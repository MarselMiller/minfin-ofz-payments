# Для ИИ-ассистентов, работающих с этим проектом

- Это проект по сбору купонных выплат и погашений ОФЗ с сайта Минфина тремя методами (`01_api` скрытое API и docx, `02_html` разбор HTML, `03_browser` браузер) со сверкой в `04_compare`. Первая ячейка каждой тетради задает период по дате выплаты (`DATE_FROM`, `DATE_TO`), итоговые файлы сверки и агента ложатся в `data_files/`.
- **Если пользователь просит собрать или обновить данные Минфина по ОФЗ за какой-либо период** (в том числе «запусти агента»), прочитай `agent/AGENTS.md` и действуй строго по нему: точные даты, оценка и разрешение словом ЗАПУСК перед любым обращением к сайту.
- Без разрешения пользователя не обращайся к minfin.gov.ru и не запускай тетради, которые ходят на сайт.
