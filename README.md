# Купонные выплаты и погашения ОФЗ с сайта Минфина: три метода и сверка

Код собирает из раздела Минфина [«Информация о выплаченных купонных доходах и погашении»](https://minfin.gov.ru/ru/perfomance/public_debt/internal/operations/payments/info_payment/) все купонные выплаты, погашения и частичные погашения ОФЗ за выбранный период в таблицу «дата выплаты, выпуск, тип платежа, сумма». Данные собираются тремя независимыми способами и выдаются, только если все три совпали строка в строку.

| Папка | Что внутри |
|---|---|
| `01_api` | метод 1: внутренний адрес ленты сайта (`/moduleRouter/`) и таблицы из docx |
| `02_html` | метод 2: страницы сайта через requests и BeautifulSoup |
| `03_browser` | метод 3: браузер через Playwright |
| `04_compare` | сверка трех методов и запись итогового файла |
| `agent` | агент: то же самое по просьбе в чате с ИИ-ассистентом |
| `data_files` | итоговые файлы (появляется после первой сверки) |

Период задается в первой ячейке каждой тетради: `DATE_FROM` и `DATE_TO` в формате ДД.ММ.ГГГГ, по дате выплаты, обе даты включительно. Тетради в архиве выполнены за 01.01.2024-27.10.2026, их выводы показывают, что должно получиться: 140 сообщений, 449 строк, три метода совпали.
