# Инструкция: как запустить на своем компьютере (Windows)

В архиве четыре тетради (три метода и сверка), папка `agent` с агентом и все, что нужно для запуска. Ниже три части: подготовка (один раз), сбор вручную в VS Code и сбор через ИИ-агента.

## Часть 1. Подготовка, один раз

**Шаг 1. Python.**
- Скачай Python 3.12 или 3.13 с https://www.python.org/downloads/ и запусти установщик.
- На первом экране обязательно поставь галочку **Add python.exe to PATH**, потом **Install Now**.
- Проверка: открой PowerShell (Пуск, набрать «PowerShell») и выполни `python --version`. Должно быть `Python 3.12.x` или `3.13.x`. Нужна версия не ниже 3.11.

**Шаг 2. VS Code.**
- Скачай и установи с https://code.visualstudio.com/.
- Открой VS Code, слева иконка из четырех квадратиков (Extensions). Найди и установи **Python** и **Jupyter**, оба от Microsoft.

**Шаг 3. Папка проекта.**
- Распакуй архив, например в `Документы`. Внутри должна быть папка с `01_api`, `02_html`, `03_browser`, `04_compare`, `agent`, `requirements.txt` и этой инструкцией.
- В VS Code: **File → Open Folder** и выбери эту папку. Если VS Code спросит, доверяешь ли ты авторам, ответь **Yes, I trust the authors**.

**Шаг 4. Окружение и библиотеки.**
- В VS Code открой терминал: меню **Terminal → New Terminal**. Внизу появится PowerShell, уже в папке проекта.
- Выполни по очереди три команды:

  ```
  python -m venv .venv
  .venv\Scripts\python -m pip install -r requirements.txt
  .venv\Scripts\python -m playwright install chromium
  ```

- Первая создает виртуальное окружение `.venv`, вторая ставит библиотеки (1-3 минуты), третья скачивает браузер для метода 3 (около 150 МБ). Активировать окружение не нужно.
- Если на первой команде ошибка «python не найден», вместо `python` попробуй `py`.

**Шаг 5. Ядро для тетрадей.**
- Открой `02_html/html.ipynb`. Справа вверху кнопка **Select Kernel** → **Python Environments** → выбери `.venv`.
- Для остальных трех тетрадей VS Code обычно подставляет `.venv` сам. Если нет, выбери так же.

## Часть 2. Сбор вручную

**Шаг 6. Даты.** В первой ячейке каждой тетради впиши период, например:

```
DATE_FROM = "01.01.2025"
DATE_TO = "31.03.2025"
```

- Формат ДД.ММ.ГГГГ, кавычки оставить. Это даты выплаты, обе включительно.
- Во всех четырех тетрадях даты должны быть одинаковые. Каждую тетрадь сохрани (Ctrl+S).

**Шаг 7. Три метода.** Открой по очереди `01_api/api.ipynb`, `02_html/html.ipynb`, `03_browser/browser.ipynb` и в каждой нажми **Run All** вверху.
- Порядок не важен, но запускай по одной: каждая ходит на сайт Минфина.
- Время при первом запуске: квартал около минуты на тетрадь; 2024-2026 целиком около 4 минут на API и HTML и 7-9 минут на браузер.
- Каждая тетрадь в конце пишет в свою папку файл вида `ofz_payments_html_2025-01-01_2025-03-31.csv`.

**Шаг 8. Сверка.** Открой `04_compare/compare.ipynb` с теми же датами и нажми **Run All**.
- Если все совпало, в выводе будет «Методы совпали. Записан data_files/ofz_payments_2025-01-01_2025-03-31.csv». Это и есть итоговый файл.
- Если методы разошлись, тетрадь остановится с ошибкой «Методы расходятся», и строкой выше видно, какой метод и на сколько строк. Итоговый файл тогда не пишется.
- Если не хватает файла какого-то метода, тетрадь скажет, какого: значит, эту тетрадь не запускали с этими датами.

**Полезно знать.**
- Скачанное методами 1 и 2 ложится в папки `raw/` и при повторном запуске не качается. Чтобы скачать все заново, удали `raw/`. Браузер каждый раз ходит на сайт целиком.
- Открыть CSV в Excel: **Данные → Из текста/CSV**, выбрать файл и кодировку **65001: Юникод (UTF-8)**. Если открыть двойным щелчком, русские буквы будут нечитаемыми.
- Если сайт ответил 503 «Доступ временно ограничен», тетрадь остановится сама. Подожди и не запускай много раз подряд.
- Если сообщение о выплате только что вышло, Минфин иногда прикладывает к нему docx позже. Тогда метод 1 его пропустит и напишет об этом, а сверка не пройдет. Через несколько дней перезапусти.

## Часть 3. Сбор через ИИ-агента

Агент делает то же самое по просьбе в чате: спрашивает разрешение, запускает три метода, сверяет и кладет итог в `data_files/`. Как он работает, подробно описано в `agent/README.md`.

**Вариант А. Claude Code в VS Code (рекомендую).** Агент работает на твоем компьютере, через твою сеть и с тем же браузером.
1. В VS Code в Extensions найди **Claude Code** от Anthropic, установи и войди в свой аккаунт Claude. Если установщик попросит Git для Windows, поставь его с https://git-scm.com/download/win.
2. Открой папку проекта (шаг 3) и выполни шаг 4, если еще не выполнял.
3. В панели Claude Code напиши, например: «Запусти агента по сбору данных Минфина с 01.01.2025 по 31.03.2025».
4. Агент сам прочитает инструкцию из `agent/AGENTS.md` и дважды попросит разрешение: на 1 запрос для оценки и на сам сбор. Разрешение дается словом **ЗАПУСК**.
5. Результат: `data_files/ofz_payments_<с>_<по>.csv` и отчет `report_<с>_<по>.md`. Ответ агент пишет тремя абзацами: «Итог», «Что произошло», «Что дальше».

**Вариант Б. Чат claude.ai.**
1. Загрузи в чат **сам архив**, а не отдельные файлы: при отдельной загрузке теряются папки, и агент не найдет тетради.
2. Напиши: «Распакуй архив, прочитай AGENTS.md и agent/AGENTS.md и запусти агента с 01.01.2025 по 31.03.2025».
3. Ограничение: код в чате выполняется в песочнице, где сайт Минфина, скорее всего, недоступен. Тогда ИИ скажет об этом прямо. Объяснить или поправить код и прогнать тесты он сможет, а собрать данные нет. Для сбора используй вариант А.

**Проверка без сайта.** Команда `.venv\Scripts\python agent\test_collect.py` проверяет разбор таблиц всех трех методов на сохраненных файлах. В конце должно быть «Все тесты прошли».
